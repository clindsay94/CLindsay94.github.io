# Connor Lindsay - Google Play Developer Resources

Welcome to the central repository and hosting site for my Google Play Developer policies and app documentation. This site serves as the official host for Privacy Policies, Terms of Service, and other required legal compliance documents for my published mobile applications.

## Purpose

Google Play requires developers to provide an active, publicly accessible URL for privacy policies and support. This GitHub Pages site fulfills that requirement, ensuring transparent access to how user data is handled, collected, and protected.

## Repository Structure

If you are browsing the source repository, the structure is organized as follows:

- `readme.md` (This page - acts as the landing page for the `.io` site)
- `_config.yml` (Jekyll configuration for GitHub Pages theme)
- `/policies/` (Directory containing individual markdown files for each app's legal documents)
- `/assets/` (Any required CSS or images)

## Contact & Support

For support inquiries, data deletion requests, or questions regarding any of the hosted privacy policies, please reach out via the contact email provided on my official Google Play Store developer page.
