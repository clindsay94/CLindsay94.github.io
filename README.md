# CLindsay94.github.io

This repository contains the source code for my personal portfolio and serves as the official host for my Google Play Developer policies and application documentation.

## Overview

The site is built using lightweight HTML5 and vanilla CSS custom properties, styled to emulate Google's Material 3 design system. It is deployed automatically via GitHub Pages.
